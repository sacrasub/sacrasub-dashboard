📓 Guia de Uso: Bullet Journal

Integração Físico-Digital

⬅ Voltar ao Dashboard

1. O que MANTER no Bujo (Alta Recompensa)

  • Calendário de Corrida (Habit Tracker): Continue! Trackers funcionam melhor no papel.
  • Barras de Progresso: Use para "Macro-Projetos" (visão geral), mas deixe os detalhes no Trello.
  • Captura Rápida: Ideias e notas rápidas durante o dia.

2. O que MIGRAR para o Digital

  • Grade Mensal: Use o Google Calendar.
  • Listas Longas de Tarefas: Trello/Google Tasks. Não reescreva tudo no papel.

3. O Ritual de Integração

Momento Ação Ferramenta
Manhã Ver Google Tasks e anotar o Big 3 Bujo + Celular
Dia Captura rápida de ideias e ordens Bujo (Físico)
Noite Migrar notas do Bujo para o Trello/GCal Bujo → Digital
Dica de Ouro: Use as mesmas cores do Google Calendar nas suas anotações do Bujo (Roxo para Teologia, Azul para Marinha, etc).
