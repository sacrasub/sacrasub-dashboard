🌅 Ritual Matinal

5-10 minutos para dominar o dia

⬅ Voltar ao Dashboard

⏰ Quando fazer?

Todos os dias pela manhã, antes de começar as atividades (idealmente após o café, antes de abrir o e-mail).

🔄 O Processo

Passo 1: Gerar o Briefing Digital

  1. No PC, clique no atalho "Sincronizar Bujo" (Somente Desktop).
  2. Aguarde 3-5 segundos.
  3. Abra o Google Tasks no celular ou PC.
⚠️ Atenção: O script de sincronização roda apenas no seu computador principal. Se estiver fora, pule este passo e consulte o Trello/GCal manualmente.

Passo 2: Preparar a Página do Dia no Bujo

Abra uma nova página no seu Bullet Journal e escreva a data no topo.

Passo 3: Anotar o "Big 3" (Tarefas Fatais)

Leia o Google Tasks e escolha apenas 3 tarefas que não podem passar de hoje.

  • Use • para tarefas normais
  • Use ⚓ para tarefas da Marinha
  • Use 🏠 para tarefas da Vila Naval
  • Use 📖 para tarefas do Seminário

Passo 4: Bloqueios de Tempo

Consulte o Google Calendar e anote os horários fixos (aulas, reuniões).

Passo 5: Espaço para Captura Rápida

Deixe o resto da página em branco para anotar coisas que surgirem durante o dia.
