🎯 Visão Geral

Seu sistema é composto por 4 ferramentas integradas:

  1. Google Calendar → Onde e quando (bloqueios de tempo)
  2. Trello → O que fazer (projetos)
  3. Google Tasks → Lista diária (sincronizada)
  4. Bullet Journal → Execução e foco

🔄 Fluxo de Trabalho

Manhã (5-10 min)

  • Verifique o Google Tasks (sincronizado automaticamente pelo script no PC).
  • Escolha e anote o "Big 3" no Bullet Journal.
  • Verifique horários no Google Calendar.

Durante o Dia

  • No PC: GCal e Trello abertos.
  • No Celular: Google Tasks para checklist rápido e GCal para agenda.
  • No Papel: Captura rápida de tudo que surgir.

Noite (5-10 min)

  • Revise o Bujo: O que foi feito?
  • Migre o importante para o Trello/GCal.
  • Limpe o Google Tasks para o dia seguinte.

⚠️ Regras de Ouro

  1. O Bujo NÃO é para planejamento - é para execução.
  2. O Trello NÃO é para tarefas diárias - é para projetos.
  3. O Google Tasks é descartável - limpe todo dia.
  4. O Google Calendar é sagrado - se está lá, cumpra.
