🛠️ Regras de Manutenção

Para manter o sistema funcionando perfeitamente, siga estas diretrizes ao criar novos arquivos:

1. Novos Scripts

New Scripts: Save new scripts in _Automation.

Sempre que criar um novo script Python (`.py`), PowerShell (`.ps1`) ou Batch (`.bat`), salve-o nesta pasta. Isso mantém a raiz dos Documentos limpa.

2. Credenciais e Segurança

Credentials: Keep sensitive files in _Config.

Arquivos como .env, credentials.json e token.json contêm senhas e chaves de acesso. Eles devem ficar isolados na pasta de configuração.

3. Logs e Registros

Logs: Scripts should be configured to write logs to _Logs.

Se o seu script gera um arquivo de texto com resultados (como log.txt ou relatorio.csv), configure-o para salvar na pasta _Logs.

🔄 Atualização Automática

Se você mover scripts ou alterar caminhos no futuro, o Windows Task Scheduler (Agendador de Tarefas) pode parar de funcionar.

Para corrigir isso automaticamente, use o script de correção que deixei para você:

_Automation\update_tasks.ps1

The update_tasks.ps1 script is available in _Automation if you ever need to update tasks again in the future.

Como usar:

  • Clique com o botão direito no arquivo.
  • Selecione "Executar com o PowerShell".
  • Ele varrerá suas tarefas agendadas e atualizará os caminhos automaticamente.

🚀 Workflow Ideal: Criando com Antigravity

Siga este passo a passo sempre que for iniciar um novo projeto ou script para garantir organização e eficiência:

  1. 1. Defina o Objetivo

    Tenha clareza do que você quer. Ex: "Criar um script que organiza downloads por data".

  2. 2. Verifique o Existente

    Antes de pedir, cheque se já existe algo similar em _Automation para evitar duplicidade.

  3. 3. Solicite ao Antigravity (Com Contexto!)

    Ao pedir, especifique onde salvar. Ex: "Crie um script Python em _Automation que... e coloque as credenciais em _Config".

  4. 4. Valide e Teste

    Rode o script. Se der erro, cole o erro no chat para o Antigravity corrigir.

  5. 5. Automatize (Opcional)

    Se funcionou, peça para criar uma tarefa agendada. O Antigravity pode criar um .bat ou atualizar o Task Scheduler para você.

Dica de Ouro: Mantenha o arquivo task.md (se você usar) atualizado para saber o estado atual do seu projeto.
